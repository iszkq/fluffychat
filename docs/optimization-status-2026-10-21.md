## 已完成

- 删除账号菜单里的“支持 FluffyChat”捐助入口及对应翻译。
- 移除 iOS ntfy 订阅页面、主题生成、注册与弹窗、构建参数、独立推送网关、
  Cloudflare ntfy 转发分支及部署文档。升级时仅保留注销旧推送的迁移：
  精确匹配当前设备及原主题，不影响其他设备；失败保留标记，下次重试。
  旧推送注销不阻塞通知点击导航，网络请求设有超时。
- 设置重置仅删除设置枚举管理的键，保留账号索引、草稿等数据；重新初始化平台默认值。
- 恢复密钥支持仅复制；MXID 登录不强制邮箱键盘；头像使用完整 Unicode 字符；
  非 MXC 图片不再误走 Matrix 媒体下载。
- 房间/空间邀请先展示邀请信息，再由用户接受或拒绝；拒绝可同时屏蔽邀请人。
  加入空间后切换对应空间列表，邀请页可在小屏幕上滚动。
- 增加 iOS 输入菜单粘贴图片入口，复用原有图片预览发送流程，处理剪贴板异常与页面销毁。
- 完整保留 `matrix:` 链接中的用户、房间、别名、事件和重复 `via` 参数；
  自定义房间链接保留账号选择和事件定位，补齐 Android scheme 声明并校验非法链接。
- 通知冷启动导航支持 Android 常驻同步模式；并发初始化去重，失败允许重试，
  Activity 重建允许重新处理。未知账号通知不跳到另一个账号。
- RTC 先发现 transports，再回退历史 well-known 及配置地址；过滤无效地址并去重；
  通话密钥限制当前房间及通话，成员 state 更新可触发刷新。
- Matrix 固定到 14.1.0，接入 SDK 安全存储回调以备份会话及密钥缓存；保留原有恢复流程。
  Keychain 读取/迁移失败不删除密钥或数据库；侧载私有 Keychain 回退继续保留。
  仅明确数据库损坏时自动重建，并先备份数据库、WAL、SHM 和 journal。
- 录音继续优先 Opus，设备不支持时才回退 AAC/M4A，正确标记扩展名及 MIME。
  原有 CAF/WebM/OGG 转换和无 EOS 兼容处理保留。
- Flutter 版本统一到 3.47.7，应用版本更新为 2.11.1+3573，更新配套依赖和锁文件。
  iOS 发布脚本使用现有 SPM 工程，移除过时的 CocoaPods 重装步骤。
- 移动构建 CI 加入本批回归，Web 部署前加入浏览器语音编码回归。

语音转文字前后端代码保持原样，没有增加额度、鉴权或并发限制。
Android 常驻同步、原生相机、云贴纸、Office、SideStore 适配和 Cloudflare 发布结构保留。
