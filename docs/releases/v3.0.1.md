# FluffyChat 3.0.1

本版本包含以下修复和发布内容：

- 修复聊天输入框中输入 `@中文` 时无法搜索成员的问题，中文昵称支持模糊匹配，选中后会正确替换查询词。
- 应用版本升级至 `3.0.1`。应用内版本展示和 Release 标签均使用纯版本号，不附加构建号或分支后缀。
- 增加自动构建并将各平台安装包上传至本 Release 的流程。

## 安装包

- Android APK：适用于 Android 手机，可直接安装；更新安装要求原应用使用本项目相同的签名密钥。
- Android AAB：用于 Google Play 等应用商店发布，不用于直接安装。
- iOS unsigned IPA：未签名包，需使用有效 Apple Developer 证书签名后安装。
- iOS SideStore IPA：适用于 SideStore、Sideloadly 等侧载工具，需由用户自行签名；免费证书的有效期和系统能力受 Apple 限制。
- macOS ZIP：解压后包含 macOS 应用。
- Windows ZIP：解压后运行其中的应用程序；首次运行可能需要确认系统安全提示。
- Linux TAR.GZ：解压后包含 Linux 应用及其运行所需文件。
- Web TAR.GZ：Flutter Web 静态站点文件，部署前应根据环境配置 `config.json`。

Android、iOS 和 macOS 安装包由 GitHub Actions 构建；桌面端及 Web 包也由同一发布流程生成。iOS 包未使用发行证书签名，不能直接安装或提交 App Store。
