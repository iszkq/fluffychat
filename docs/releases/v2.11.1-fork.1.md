# FluffyChat 定制版 2.11.1 · fork.1

本版本由 [iszkq/fluffychat](https://github.com/iszkq/fluffychat) 维护，更新记录仅描述本分支的改动。

## 本次源码修复

- 更新成功弹窗移除“支持”按钮和捐助文案，仅保留更新记录与关闭。
- 更新记录、源码和问题反馈指向本仓库；关于页面增加更新记录入口。
- 更新提示及关于页面显示构建号，同版本的不同构建也能识别更新。
- Release 改为校验本分支的版本说明，不再运行上游的自动构建、上传和应用商店部署。
- 修复 Web 语音编码测试的资源路径，避免构建前测试超时。

## 已包含的上一批改进

- iOS 输入菜单支持粘贴图片，复用图片预览与发送流程。
- 房间和空间邀请先展示详情，再选择接受、拒绝或拒绝并屏蔽。
- 完善 Matrix 深链、事件定位、多账号处理和 Android 通知启动导航。
- 更新通话服务发现与状态刷新，兼容新 RTC 服务发现方式并保留旧地址回退。
- Matrix SDK 升级至 14.1；完善安全存储和数据库恢复，仅在明确损坏时备份后重建。
- 重置设置保留账号索引、草稿等数据；恢复密钥“复制”只复制，不再弹分享面板。
- 录音优先 Opus，不支持时回退 AAC；保留原有语音容器兼容处理。
- 删除账号菜单捐助入口和旧 iOS ntfy 通知集成，保留旧推送注销迁移。

## 已知限制

- 移除 ntfy 不代表已实现新的 iOS 后台推送。iOS 锁屏或进程被系统挂起后，不能据此版本承诺可靠通知。
- SideStore 版仍需自行签名；Android 常驻同步模式仍依赖系统允许应用后台运行。
- 数据库恢复、历史消息解密、蓝牙通话和后台行为仍需真机验证，构建成功不能替代这些验证。
- 语音转文字调用方式保持不变，没有新增用户额度、鉴权或并发限制；原有 25 MB 单文件大小检查仍保留。
